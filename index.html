How this was built

The short version of the notebook this page is based on.

  1. Cleaned the USA Housing dataset and dropped the free-text address column.
  2. Checked feature–price relationships with scatterplots and a correlation heatmap before modelling.
  3. Split 80/20 into train and test sets, then standardised all five features with StandardScaler.
  4. Fit a multiple linear regression model and validated its assumptions — linearity, homoscedasticity, normal residuals, independence, and low multicollinearity (via VIF).
  5. Checked the residual plots after fitting: roughly bell-shaped and centred at zero, with no funnel pattern — confirming linear regression was a reasonable choice for this data.
This page doesn't hardcode any coefficients. On load, it asks a live Flask API to retrain on the current USA_Housing.csv and report back the coefficients, ranges, and metrics — so replacing the CSV and restarting the API is the only step needed to update everything here. The underlying dataset is a synthetic teaching dataset built from realistic U.S. housing statistics, so estimates are illustrative and not a real appraisal tool.
